# turbomcp-ext-apps

The TurboMCP v4 Apps extension (SEP-1865, extension id `io.modelcontextprotocol/ui`) — a Phase-0 skeleton; the full implementation is scheduled after v4 GA.

This package currently reserves an extension identifier. It has no usable Apps
implementation and is not re-exported as a supported facade feature. Apps
support requires its own implementation, working example, and compatibility
and security tests before it can be advertised.
